# Content

Responsible for providing content, such as CMS pages.

## Tables

| Table           | Description |
| --------------- | ----------- |
| `content_pages` | CMS pages   |

## Events emitted

| Event                  | When                  |
| ---------------------- | --------------------- |
| `PagePublishedEvent`   | A page is published   |
| `PageUnpublishedEvent` | A page is unpublished |

## Dependencies

None.
