# Media

Responsible for uploading and managing media (images used across products
and content).

## Tables

| Table         | Description   |
| ------------- | ------------- |
| `media_media` | Media records |

## Events emitted

| Event               | When              |
| ------------------- | ----------------- |
| `MediaCreatedEvent` | Media is uploaded |
| `MediaDeletedEvent` | Media is deleted  |

## Dependencies

None.
